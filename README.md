# EgoM³ project page

Project page of *EgoM³: Multi-View Multi-Human Mesh Reconstruction from Egocentric Videos*.

The page is static: `index.html`, with styles and scripts in `static/`.
To preview it locally, run `python3 -m http.server` in this directory.

To add a result video, put the mp4 in `static/videos/` and set the `data-video` attribute of its button in the Video Results section of `index.html`.
