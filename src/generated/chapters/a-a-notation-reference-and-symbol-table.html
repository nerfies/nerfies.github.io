A A Notation Reference and Symbol Table#

This appendix provides a unified reference for mathematical notation used throughout the survey.

  • x \in \mathbb{R}^{d_{\text{vocab}}} or x \in \{1, \ldots, V\}: input token or token index

  • h^\ell \in \mathbb{R}^{d_{\text{hidden}}}: activation (residual stream) at layer \ell

  • z_i \in \mathbb{R}^{d_{\text{sparse}}}: sparse feature activation from dictionary

  • f_j \in \mathbb{R}^{d_{\text{hidden}}}: feature vector (direction in activation space)

  • W_{\text{in}}, W_{\text{out}} \in \mathbb{R}^{d_{\text{hidden}} \times d_{\text{sparse}}}: SAE encoder/decoder weights

  • b_{\text{in}}, b_{\text{out}} \in \mathbb{R}^{d_{\text{sparse}}}: SAE encoder/decoder biases

  • W_Q, W_K, W_V \in \mathbb{R}^{d_{\text{hidden}} \times d_{\text{head}}}: attention projection matrices

  • W_1 \in \mathbb{R}^{d_{\text{hidden}} \times d_{\text{mlp}}}, W_2 \in \mathbb{R}^{d_{\text{mlp}} \times d_{\text{hidden}}}: MLP weight matrices

  • \text{patch}(C, h_{\text{clean}}, h_{\text{corrupt}}): causal intervention at component C

  • v_{\text{steer}} \in \mathbb{R}^{d_{\text{hidden}}}: steering vector

  • \alpha: scaling factor for steering vector application

  • L: loss function (typically cross-entropy for language modeling)

  • \theta: model parameters

  • \lambda: sparsity regularization coefficient or other penalty weights

  • p(y|x): probability of output y given input x

  • \log p(y|x): log probability (used for loss)

  • \mathbb{E}[\cdot]: expectation over data distribution

  • \mathbb{E}[h \mid \text{condition}]: expectation of activations conditioned on an event

  • \perp: orthogonality (features or vectors are perpendicular)

  • \|v\|: Euclidean norm of vector v

  • v \cdot w or \langle v, w \rangle: dot product

  • D_{\text{KL}}(P \| Q): KL divergence between distributions P and Q

  • \sigma: sigmoid function

  • \odot: element-wise (Hadamard) product

  • ReLU: rectified linear unit activation function

A.1 Dimensions and Scaling#

  • n_{\text{tokens}}: number of tokens in dataset

  • n_{\text{samples}}: number of forward passes or interventions performed

  • T: sequence length (context length)

  • B: batch size

  • O(\cdot): Big-O asymptotic complexity notation
