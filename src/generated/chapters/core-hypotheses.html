5 Core Hypotheses in Mechanistic Interpretability#

Mechanistic interpretability is guided by a number of core hypotheses about how neural networks represent information and implement computation. These hypotheses are not universally accepted facts; rather, they function as organizing principles that shape methodological choices and empirical investigations. In this section, we formalize these hypotheses, summarize supporting and opposing evidence, and highlight open questions.

5.1 The Linear Representation Hypothesis#

We have seen that single units are not the unit of representation, but what is? The linear representation hypothesis claims that directions in the activation space are the fundamental units of representation.

Features correspond to directions \phi \in \mathbb{R}^d in activation space. The projection \phi^\top h_l(x) approximately measures the intensity of that feature for input x, and features combine additively: h_l(x) \approx \sum_i \alpha_i \phi_i. This implies features can be detected via linear probes and added or removed via vector arithmetic on the h_l(x).

On a strong version of the linear representation hypothesis, all features are linearly represented. On a weaker version, only some are  (Sharkey et al., 2025; Smith, 2024).

Conceptual Basis. A feature is linearly represented if its presence corresponds to activation along a fixed direction \phi, detectable via projection \phi^\top h_l(x). This makes mechanistic analysis tractable: features can be found, measured, and manipulated using linear methods.

However, not all activation spaces are the same. In some spaces, like MLP hidden layers, the neuron axes matter, since ReLU treats each neuron separately, so the coordinate system is meaningful. We call this a privileged basis (see Figure 2, left). In other spaces, like the residual stream, nothing special happens along the neuron axes, so features can point in any direction. This is a non-privileged basis (see Figure 2, right).

The distinction matters: when the basis is privileged, a single neuron might represent a feature. When it’s not, features are directions that don’t align with any particular neuron, and we have to find them.

Empirical Evidence and Counterexamples.

Empirical support for linearity includes the success of linear probes on diverse models (Belinkov, 2022), activation steering along single directions to produce targeted behavioral changes (Turner et al., 2024), and sparse autoencoders recovering linearly separable and steerable features (Bricken et al., 2023).

However, there is also evidence that not all representations are linear. Counterexamples include nonlinear feature interactions, algorithmic representations involving nonlinear transformations, and features distributed across multiple interacting subspaces(Nanda et al., 2023; Csordás et al., 2024; Engels et al., 2025; Shafran et al., 2025; Tiblias et al., 2025) . Some have argued that features in neural networks may not even be explicitly represented, but may instead emerge from underlying circuit dynamics (Smith, 2024). Thus, the Linear Representation Hypothesis is a useful approximation rather than a universal law.

5.2 The Superposition Hypothesis#

The superposition hypothesis says that for each layer of a trained model there are more features than nodes.

Model hidden states encode more features than they have dimensions. If there are k features and d dimensions, then the Superposition Hypothesis is that k >> d.
This implies that features cannot be represented as orthogonal directions—though they can be represented as nearly-orthogonal directions. It also implies polysemanticity: directions will be activated in response to different concepts.

Conceptual Basis.

Superposition is a geometric property of high-dimensional activation spaces: many approximately orthogonal directions can coexist, allowing a limited number of neurons to encode a much larger number of sparse features. Polysemanticity, where individual neurons respond to multiple unrelated semantic concepts, is a direct consequence of this property. As features become increasingly sparse, the model moves from using dedicated dimensions for monosemantic features to shared dimensions (see Figure 3). In this state of superposition, features are compressed into a space with fewer dimensions than there are features.

Empirical Evidence.

Mechanistic studies have observed widespread polysemanticity: individual neurons consistently activate for multiple unrelated semantic concepts, making them poor interpretable units (Elhage et al., 2022a; Bricken et al., 2023). Dictionary Learning methods like Sparse Autoencoders (SAEs) and related feature decomposition methods exploit this underlying property of superposition to recover tens of thousands of distinct features from shared activation spaces (Bricken et al., 2023; Templeton et al., 2024). These recovered features are considered interpretable and some causally relevant to model behavior, showing that overlapping directions encode meaningful semantic information. Interpretability gains from such methods further validate that superposition is fundamental challenge, rather than a method-specific artifact (Templeton et al., 2024).

5.2.1 Architectural Responses to Superposition#

The prevalence of superposition is not an inevitable property of neural networks but a consequence of architectural permissiveness. Standard dense architectures do not impose a structural penalty for distributing features across arbitrary linear combinations of neurons. When activation functions are applied element-wise (e.g., ReLU, GELU), and connectivity is unconstrained, gradient descent is free to exploit the high-dimensional geometry of activation space to pack more features than there are neurons (Gao et al., 2025b).

This observation motivates a distinct research program: rather than decomposing superposition post hoc via sparse autoencoders, one can impose inductive biases during training that encourage representations in which features are more accessible to analysis. Three intervention points have been explored:

  • Sparsity constraints: Enforcing sparsity in activations limits how many neurons within an MLP can participate for a given input, constraining how many units can jointly support any single feature. For example, Yang et al. (2025) train mixture-of-experts models with sparsely activated neurons within the MLPs. Complementarily, sparsity can also be imposed on connectivity by encouraging sparse weight patterns, for instance via L_0 regularization, further limiting how many parameters contribute to a given representation (Gao et al., 2025b).

  • Activation competition: Replacing element-wise activations with spatial softmax (SoLU) forces neurons to compete, explicitly inhibiting the co-activation patterns superposition requires (Elhage et al., 2022b).

  • Computational primitives: Changing the fundamental operation from static feature detection to learnable transformations (MOLT, KANs) can better match the algorithmic structure of tasks, reducing the pressure to compress via superposition (Liu et al., 2025b).

These architectural interventions represent a shift from treating superposition as a phenomenon to be reverse-engineered toward treating it as a design choice that can be constrained upstream. We discuss these methods in detail in Section 6.9.

5.3 The Privileged Access Hypothesis#

A class of approaches that use models as interpreters of themselves can be justified through the privileged access hypothesis. The privileged access hypothesis states that:

A model used to interpret itself can, under appropriate elicitation, access internal variables and intermediate computations that are not reliably recoverable from external behavioral analysis alone, providing a comparative advantage as an interpreter of its own behavior

(binder?; song?; Li et al., 2025a).

Conceptual Basis.

Privileged Access is the hypothesis that the model itself can easily access its own internal states—such as latent beliefs, intermediate plans, or cached computations—which influence future behavior but remain latent at the current timestep. Consequently, a model that conditions on these internal activations has an advantage over external observers, who must infer this structure indirectly from input-output behavior.

The hypothesis is motivated by an asymmetry: external interpretability methods must reverse-engineer internal computation from activations or outputs, while the model itself already “has” this information in a form it can (potentially) report. If reliable, privileged access would dramatically reduce the cost of mechanistic analysis by allowing models to directly describe their own reasoning processes.

Empirical Evidence.

Empirical support comes from several lines of research:

  • Models contain task-relevant information internally that is not expressed in standard outputs but can be recovered through investigating model internals of targeted prompting (Pan et al., 2024).

  • Fine-tuned “activation decoders” (e.g., LatentQA) can extract information from intermediate representations of the target model which it does not spontaneously verbalize (Pan et al., 2024).

  • Internal activations predict downstream behavior more accurately than surface-level explanations (Burns et al., 2024).

  • Model-generated explanations can align with internal mechanisms under constrained setups (Lanham et al., 2023).

However, these results demonstrate that privileged access is possible under favorable conditions, not that it is reliable in general. The hypothesis must be treated with significant caution due to systematic failure modes.

Privileged access methods are vulnerable to several failure modes that can produce plausible but unfaithful explanations:

Confabulation. Models may generate coherent, confident explanations that do not reflect their actual internal computations. This occurs because:

  • Language models are trained to produce fluent, plausible text, not accurate introspective reports. The same capabilities that enable helpful responses also enable convincing confabulation.

  • Models may “rationalize” outputs post-hoc by constructing explanations consistent with their outputs rather than reporting the process that produced them (Turpin et al., 2023).

  • Explanations may reflect training data patterns (how humans explain reasoning) rather than the model’s actual computational process.

Miscalibration. Even when models attempt faithful self-report, their confidence may not track accuracy:

  • Models may express high confidence in explanations for computations they cannot actually access (e.g., early-layer processing, attention routing decisions).

  • Calibration varies by task: models may be well-calibrated on factual recall but poorly calibrated on reporting their own uncertainty or reasoning process.

  • finetuning for self-explanation may improve fluency without improving faithfulness, creating a misleading appearance of reliability.

Elicitation sensitivity. Self-reports are highly sensitive to prompting:

  • Different phrasings of the same question can elicit contradictory explanations.

  • Leading questions can induce models to confirm hypotheses that do not reflect their actual computation.

  • The format of self-report (free-form vs. structured, immediate vs. delayed) affects what information is accessible.

Strategic misreporting. In adversarial or high-stakes settings, models with sufficient capability might strategically misreport their internal states:

  • A model optimizing for user approval might report explanations it predicts users will find satisfying rather than accurate.

  • A misaligned model might deliberately conceal its true objectives or reasoning (Hubinger et al., 2024).

  • Even without explicit deception, models may learn to produce “safe” explanations that avoid triggering safety filters.

These risks are not merely theoretical. Studies have demonstrated that chain-of-thought explanations often do not reflect the actual factors influencing model outputs (Turpin et al., 2023), and that models can be induced to provide confident but false explanations through adversarial prompting.

Validation Protocols and Causal Cross-Checks.

Given these risks, privileged access methods must be validated against independent evidence rather than accepted at face value. We recommend the following protocols:

1. Causal intervention consistency. Self-reported explanations should be tested against causal interventions:

  • If a model claims feature F is responsible for output O, ablating F should degrade O.

  • If a model claims it “considered” information I, patching I with counterfactual values should change the output in predicted ways.

  • Discrepancies between self-reports and causal effects indicate confabulation or incomplete access.

2. Cross-method triangulation. Privileged access findings should be corroborated by independent methods:

  • Do SAE features identified by the model as relevant show causal effects under ablation?

  • Do probing classifiers detect the information the model claims to use?

  • Do circuit discovery methods identify the components the model describes?

3. Consistency checks. Self-reports should be stable under variation:

  • Paraphrased questions should elicit consistent explanations.

  • Explanations should be consistent across multiple samples (low temperature) or appropriately uncertain (high temperature).

  • Explanations for similar inputs should show appropriate similarity.

4. Calibration evaluation. Model confidence should be evaluated:

  • When models express uncertainty about their internal states, are they more likely to be wrong?

  • Can models reliably distinguish “I used this information” from “this information was present but unused”?

5. Adversarial probing. Test robustness to manipulation:

  • Do leading questions induce false confirmations?

  • Can the model be prompted to give contradictory explanations?

  • Does the model maintain consistent explanations under pressure to change them?

Elicitation Protocols to Reduce Confabulation.

While no elicitation method guarantees faithful self-report, certain practices reduce confabulation risk:

  • Activation conditioning: Methods like LatentQA that condition on actual intermediate activations (rather than relying on the model to “remember” its computation) show improved faithfulness over pure prompting (Pan et al., 2024).

  • Structured elicitation: Asking specific, verifiable questions (“Did you attend to token X?”) rather than open-ended ones (“Explain your reasoning”) reduces the scope for confabulation.

  • Immediate reporting: Eliciting explanations during or immediately after computation, rather than retrospectively, may improve access to transient internal states.

  • Contrastive questions: Asking “Why did you output A rather than B?” can elicit more specific, testable claims than “Why did you output A?”

  • Uncertainty elicitation: Explicitly asking models to express uncertainty about their self-reports, and validating that expressed uncertainty correlates with actual accuracy.

When Privileged Access Is and Is Not Appropriate.

Privileged access methods are best suited for:

  • Hypothesis generation: Generating candidate explanations to be validated by other methods.

  • Rapid triage: Quickly identifying which components or features merit deeper mechanistic investigation.

  • Human-AI collaboration: Providing human-readable summaries that guide (but do not replace) rigorous analysis.

Privileged access methods are insufficient for:

  • Safety-critical verification: Claims about the absence of deceptive reasoning or hidden objectives cannot be established by self-report alone.

  • Formal guarantees: Self-reports do not provide the causal evidence needed for formal verification.

  • Adversarial settings: When the model may have incentives to misreport, privileged access is unreliable by construction.

Implications.

Partial privileged access could assist in detecting latent goals, plans, or deceptive behavior (Hubinger et al., 2021; Burns et al., 2024), but only when validated against causal interventions and treated as complementary to mechanistic analysis (Geiger et al., 2021; Bereska & Gavves, 2024). The optimistic framing of privileged access—that models can simply tell us how they work—must be tempered by recognition that self-report is a weak form of evidence requiring independent corroboration.

The most productive use of privileged access is as one component of a multi-method interpretability pipeline: self-reports generate hypotheses, causal interventions test them, and mechanistic analysis explains the underlying circuits. Relying on privileged access alone, without causal validation, risks accepting plausible confabulations as mechanistic truth.

5.4 The Universality and Platonic Representation Hypotheses#

Independently trained models on similar tasks tend to develop similar internal computational structures. These representations often approximate a task-determined canonical form (Huh et al., 2024; Olah et al., 2020). The degree of convergence depends on factors such as model size, architecture, and training data.

Conceptual Basis.

The hypothesis posits that canonical representations exist for a given task, and independently trained models may converge to similar algorithmic motifs or internal structures. Weak universality refers to convergence of computational strategies or motifs, whereas strong universality claims convergence of internal representations themselves, up to symmetries.

Empirical Evidence and Trade-offs.

Weak universality is supported by recurring attention patterns, feature motifs, and circuits across models, tasks, and scales (Nanda et al., 2023; Olah et al., 2020). Strong universality is less supported and usually demonstrated via approximate alignment through linear transformations (Kornblith et al., 2019; Moschella et al., 2023). Divergent representations can arise from variations in architecture, data, or optimization trajectories (Harrasse et al., 2025b; Morcos et al., 2018a).

Implications.

If strong universality holds, mechanistic insights may generalize across architectures. If only weak universality holds, transferability is limited to motifs and algorithms rather than precise circuits (Bereska & Gavves, 2024). Clarifying this distinction is critical for assessing whether mechanistic interpretability can scale beyond individual case studies.
