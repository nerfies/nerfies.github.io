D Mathematical Foundations#

This appendix provides background on key mathematical frameworks used in mechanistic interpretability.

D.1 Sparse Coding Theory#

Sparse autoencoders are grounded in sparse coding: the hypothesis that the brain (and neural networks) represent information via sparse, interpretable basis vectors.

Sparse coding problem: Given data x, find dictionary D and sparse codes z such that: \begin{equation*} x \approx Dz, \quad \|z\|_0 \text{ small} \tag{7} \end{equation*}

In practice, \ell_1 regularization is used instead of \ell_0 (NP-hard): \begin{equation*} \min_D \min_z \|x - Dz\|^2 + \lambda \|z\|_1 \tag{8} \end{equation*}

SAEs implement this with neural networks: D = W_{\text{out}}, codes are z = \text{ReLU}(W_{\text{in}} x + b).

D.2 Causal Inference Basics#

Mechanistic interpretability relies on causal reasoning: determining whether a component is necessary and sufficient for a behavior.

D.2.1 Necessity#

A component C is necessary for behavior B if: \begin{equation*} \text{Remove } C \Rightarrow B \text{ disappears} \tag{9} \end{equation*}

Tested via ablation: measure effect of removing C on downstream loss or output distribution.

D.2.2 Sufficiency#

A component C is sufficient for behavior B if: \begin{equation*} \text{Only } C \text{ is active} \Rightarrow B \text{ occurs} \tag{10} \end{equation*}

Tested via interchange interventions: replace C in a clean example with C from a different example, verify behavior changes as expected.

D.2.3 Causal Abstraction#

Causal abstraction formalizes when a high-level description (“this head implements copying”) correctly describes lower-level computation.

A high-level abstraction is causally correct if interventions on the high-level description produce equivalent causal effects as interventions on the low-level system.

This is formalized via causal diagrams: high-level variables correspond to low-level variables via abstraction maps \phi, and interventions commute: \begin{equation*} \text{Intervene at high level} \xrightarrow{\phi} \text{Intervene at low level} \tag{11} \end{equation*}

D.3 Singular Learning Theory (SLT)#

SLT provides geometric analysis of neural network learning and generalization.

D.3.1 The Local Learning Coefficient#

For a loss landscape \mathcal{L}(\theta) at a solution \theta^*, the Local Learning Coefficient (LLC) is: \begin{equation*} \text{LLC}(\theta^*) = \frac{d}{2} - \frac{1}{2} \lambda_1(\theta^*) \tag{12} \end{equation*}

where d is the dimension of the parameter space and \lambda_1 is the largest eigenvalue of the Hessian.

Interpretation: LLC measures the effective complexity of a solution. Lower LLC means the solution is sharper (more singular), indicating earlier learning and less overfitting.

D.3.2 Generalization Bounds#

SLT provides generalization bounds: \begin{equation*} \text{Test loss} \lesssim \text{Train loss} + \frac{\text{LLC}}{n_{\text{samples}}} \log n_{\text{samples}} \tag{13} \end{equation*}

This suggests that minimizing LLC (finding sharp minima) improves generalization—counterintuitive given the typical view that sharp minima overfit.

D.3.3 Phase Transitions#

SLT predicts phase transitions during learning: as loss decreases, the Hessian’s spectral properties change sharply at critical loss values. These correspond to emergence of capabilities (grokking).

D.4 Linear Representation Hypothesis#

The Linear Representation Hypothesis claims that information about a concept can be extracted via a linear function of activations: \begin{equation*} \text{concept} = w \cdot h + b \tag{14} \end{equation*}

This is central to mechanistic interpretability because it enables:

  • Feature extraction via SAE: linear combinations of basis vectors approximate features

  • Steering via addition: adding a vector to activations changes behavior predictably

  • Circuit analysis: attention and MLP operations are approximately linear in feature space

Empirically, linearity holds for many concept-level analyses but breaks down for complex reasoning, arithmetic, and modular structures.

D.5 Superposition and High-Dimensional Geometry#

In d-dimensional space, many nearly-orthogonal directions exist. If d = 4096, you can fit thousands of orthogonal directions.

Superposition hypothesis: neural networks exploit this by encoding multiple features in superposition—as nearly-orthogonal directions. A polysemantic neuron activates for a mixture of these directions.

Formally, if features f_1, \ldots, f_m \in \mathbb{R}^d are nearly-orthogonal (|f_i \cdot f_j| \ll 1 for i \neq j), then linear combinations: \begin{equation*} h = \sum_i \alpha_i f_i \tag{15} \end{equation*}

can encode many features efficiently. Individual neurons (components of h) will be polysemantic.

D.6 Information Theory Basics#

Mechanistic interpretability uses information-theoretic concepts to measure what information is preserved across layers.

Mutual information: I(X; Y) measures how much knowing X tells you about Y.

Entropy: H(X) = -\sum_x p(x) \log p(x) measures uncertainty in X.

KL divergence: D_{\text{KL}}(P \| Q) = \sum_x P(x) \log \frac{P(x)}{Q(x)} measures dissimilarity between distributions.

These are used to analyze:

  • Feature extraction quality: how much information do SAE features retain?

  • Attention routing: how much information flows through different heads?

  • Circuit discovery: do identified components preserve information about behavior?
