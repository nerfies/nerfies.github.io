6 Feature Extraction and Analysis#

The critical notions introduced in Section 4, together with the hypotheses about the structure of neural network representations discussed in Section 5, provide the conceptual foundation for developing methods to identify and analyse manipulable internal objects associated with concepts of interest, i.e., features. One straightforward paradigm is to decompose model activations into sparse linear features. Sparse autoencoders (SAEs) provide a principled example of this approach, learning to represent any input activation with a subset of a large dictionary of monosemantic, interpretable features (Cunningham et al., 2024).

This section first introduces the canonical sparse coding problem and links it to SAEs, reviews how SAEs extract interpretable features, and then provides a practical overview and comparison of major SAE variants. We then introduce methods for multi-layer feature extraction and analysis, such as transcoders and crosscoders, and compare them with SAEs as well as with a broader range of alternative feature-extraction methods.

6.1 The Sparse Coding Problem#

Early neuroscience studies posited that brains represent information using sparse, interpretable basis signals (Barlow, 1961; Field, 1994). This hypothesis further motivated research to decompose natural images and compare the decomposed signals with cell activities in the primary visual cortex, finding surprising alignment (Olshausen & Field, 1996; 1997). At the same time, the signal processing community has also examined representing a given signal as the sum of a subset of basis signals from a given overcomplete dictionary (Mallat & Zhang, 1993; Chen et al., 1998). Studies on learning better overcomplete dictionaries for high-quality representations also thrived (Lewicki & Sejnowski, 2000; Aharon et al., 2006). Together, they framed the sparse dictionary learning research question, with SAEs serving as a modern algorithm that uses neural network activations as the signal. Specifically, given data h, a sparse dictionary learning method finds the dictionary D and sparse codes z such that \begin{equation*} h \approx Dz \text{ and } \|z\|_0 \text{ is small}. \tag{2} \end{equation*} SAEs implement this with neural networks: h are model activations, D = W_{\text{out}} is an overcomplete dictionary to learn, and the sparse codes are z = \sigma(W_{\text{in}} h + b_{\text{in}}). Note that conventional dictionary methods usually run the algorithm to find a z for each h, which does not scale to modern language models. In contrast, SAEs use a nonlinear encoder E to predict the coefficients for different input activations.

6.2 Sparse Autoencoders#

SAEs (Figure 6) extract monosemantic features from polysemantic model activations. They are trained to reconstruct activations at a specific location in neural networks, such as the output of an MLP block or an entire transformer layer (i.e., the residual stream), while keeping only a few features active in any given forward pass.

A sparse autoencoder learns a component-specific encoder–decoder pair E : \mathbb{R}^d \rightarrow \mathbb{R}^{d_{\text{sparse}}}, \qquad D : \mathbb{R}^{d_{\text{sparse}}} \rightarrow \mathbb{R}^d, such that activations of a particular model component at a given layer, h_\ell \in \mathbb{R}^d (e.g., the output of the layer-\ell MLP block), are reconstructed as \hat{h}_\ell = D(E(h_\ell)), while encouraging the feature activations z=E(h_\ell) to be sparse. Usually, d_{\text{sparse}} = ed, where e is an integer expansion factor.

Canonical Formulation.

Given activations of a model component h_\ell \sim \mathcal{H}, where \mathcal{H} is the distribution of that component’s activations over a large corpus, the canonical SAE objective is \mathcal{L}_{\text{SAE}} = \mathbb{E}_{h_\ell \sim \mathcal{H}} \left[ \| h_\ell - D (z) \|_2^2 + \lambda \| z \|_1 \right], \quad z = E(h_\ell), where \lambda > 0 controls sparsity (Cunningham et al., 2024). Canonical SAEs use L_1 regularisation instead of L_0 regularisation. This is because, for each feature, L_0’s derivative is almost everywhere zero and thus does not provide useful signals for promoting feature sparsity during gradient descent. Additionally, the decoder columns are typically constrained to unit norm. This is to prevent the case where the SAE learns to reduce its L_1 loss by generating smaller values of z—not exactly 0 so that many features can be active, each having a small coefficient—and enlarging the norm of each column of the decoder to compensate. In this way, the SAE output remains the same, while L_1 loss can be substantially reduced, without any real gain in sparsity.

Why SAEs Work.

SAEs are motivated by the hypothesis that a model’s activations can be approximated as linear combinations of many latent feature directions, which can be regarded as an extension of the linear representation hypothesis discussed in Section 5.1. Sparsity means that only a small number of features are active for any given token or input, but not that the hidden state itself is sparse. Early sparse dictionary learning studies (Olshausen & Field, 1996; Lewicki & Sejnowski, 2000; Aharon et al., 2006) give us fair confidence that, if the hypothesis holds, dictionary learning can recover the structure as an overcomplete dictionary. These findings motivate using SAEs as a modern adaptation to extract monosemantic directions from the activations of neural networks (Cunningham et al., 2024; Bricken et al., 2023).

From Monosemanticity to Concept Identification.

For each input activation, the raw SAE outputs are just a small set of vectors. Practical interpretability requires identifying the semantic concepts these vectors correspond to in natural language (so that they become human-understandable features). Empirically, SAE features selectively activate on structured token patterns that recur across input sequences, suggesting sensitivity to specific abstract semantic, functional, or lexical concepts (Marks et al., 2024b). Automated analysis pipelines (Gur-Arieh et al., 2025a; Paulo et al., 2025b) aggregate highly activating inputs to infer the concept each feature captures (see Section 12.6 for a detailed discussion).

Training Dynamics and Evaluation.

SAE training is sensitive to initialisation, sparsity strength, and decoder normalisation. Without proper constraints and hyperparameters, the features may collapse, duplicate, or absorb one another. SAEs are typically evaluated for reconstruction loss (fidelity of activation reconstruction), feature absorption (how often a general feature fails to fire because a more specific feature has absorbed its direction), and downstream test loss recovery (whether replacing activations with reconstructions preserves model behaviour). Together, these metrics assess both the quality of the decomposition and its mechanistic relevance to the original model’s computation.

6.3 SAE Variants and Architectural Improvements#

There are several variants of the standard SAE. One key reason to use alternatives is that standard SAE training penalises activation magnitude, which can lead to low activation even when a feature is clearly present (the shrinkage effect). Different optimisation frameworks also have different tunable parameters. The choice depends on the analysis goal, target layer type, model size, and budget constraints.

Gated SAEs introduce multiplicative gates to decouple feature selection from magnitude: z = \underbrace{\mathbbm{1} \left( (W_{\text{gate}} h_\ell + b_{\text{gate}}) > 0 \right)}_{\text{Gating Path}} \odot \underbrace{\sigma_{\text{ReLU}}(W_{\text{in}} h_\ell + b_{\text{in}})}_{\text{Magnitude Path}}, where h_\ell \in \mathbb{R}^d denotes activations at layer \ell, W_{\text{in}} \in \mathbb{R}^{{d_{\text{sparse}}} \times d} and b_{\text{in}} \in \mathbb{R}^{d_{\text{sparse}}} are encoder E parameters, W_{\text{gate}} \in \mathbb{R}^{{d_{\text{sparse}}} \times d} and b_{\text{gate}} \in \mathbb{R}^{d_{\text{sparse}}} are the gate parameters, and \odot denotes element-wise product. This mitigates shrinkage effects induced by the L_1 penalty (Rajamanoharan et al., 2024a).

JumpReLU SAEs (Rajamanoharan et al., 2024b) learn per-feature activation thresholds. Given the encoder pre-activation a = W_{\text{in}} h_\ell + b_{\text{in}}, let a_i denote its i-th entry. The activation value of the i-th feature after applying JumpReLU is z^i = \sigma_{\text{JumpReLU}}(a_i) = \begin{cases} a_i & \text{if } a_i > \tau_i \\ 0 & \text{otherwise}, \end{cases} where \tau_i is a learned threshold parameter. Straight-through estimators (Bengio et al., 2013) are used during training to enable gradient flow.

Top-k SAEs (Gao et al., 2025) impose an explicit hard sparsity constraint. Let a = W_{\text{in}} h_\ell + b_{\text{in}} \in \mathbb{R}^{d_{\text{sparse}}} denote encoder pre-activations. Top-k SAEs define the i-th feature’s activation as z^i = \sigma_{\text{TopK}}(a_i) = \begin{cases} a_i & \text{if } i \in \mathcal{I}_k(a) \\ 0 & \text{otherwise}, \end{cases} where \mathcal{I}_k(a) indexes the k largest entries of a. This formulation explicitly enforces \|z\|_0 \le k—a more direct feature-sparsity constraint than L_1 regularisation. Notably, as it does not suppress activation magnitudes, it avoids the feature-shrinkage issue observed in L_1-based SAE training (Gao et al., 2025).

Batch Top-k SAEs relax the fixed per-example sparsity constraint of standard Top-k SAEs by enforcing the sparsity budget across an entire batch instead (Bussmann et al., 2024). For a batch of encoder activations \big[\, a^{(1)}, \dots, a^{(B)} \,\big] \in \mathbb{R}^{d_{\text{sparse}} \times B}, where B is the batch size, Batch Top-k retains the largest Bk activation values in the batch. Specifically, let \mathcal{I} \coloneqq \arg\max_{\substack{ \mathcal{S}\subseteq \{1,\ldots,B\}\times \{1,\ldots,d_{\text{sparse}}\}\\ |\mathcal{S}|=Bk }} \sum_{(b,j)\in\mathcal{S}} a_j^{(b)}. In each batch, the activation value of the j-th feature in the b-th sample is z^{j, (b)} = \sigma_{\text{Batch-TopK}}\!\left(a_j^{(b)}\right) = \begin{cases} a_j^{(b)}, & (b,j)\in\mathcal{I},\\ 0, & \text{otherwise}. \end{cases}

That is, each batch exactly retains Bk features, while individual samples may have more or fewer active features than k. This loose constraint allows the model to allocate representational capacity adaptively across samples. During inference, Batch Top-k SAEs instead use the JumpReLU function with an inferred global threshold to determine which features are active for each input, so that an input’s activations do not depend on the rest of the batch.

Different SAE variants may implement distinct sparsity constraints. No single variant is optimal across all scenarios.

6.4 Empirical Comparisons of SAE Variants#

The SAE variants in Section 6.3 differ principally in how they enforce sparsity, and those differences map onto distinct analysis settings.

Hard-constraint formulations (e.g., Top-k) directly enforce sparsity and suit tight compute budgets. Learned-threshold (e.g., JumpReLU SAE) and gated formulations usually achieve better reconstruction results and suit generous tuning budgets. Cross-layer variants (discussed in Section 6.6) analyse computations across layers that a single dictionary cannot represent at all. This subsection discusses the setting in which each variant is used and the evidence it provides. We particularly discuss four factors that account for most of the variation:

  1. Analysis goal: exploratory discovery vs. targeted investigation vs. deployment/monitoring

  2. Layer type: residual stream vs. MLP output vs. attention output

  3. Model scale: small (<1B) vs. medium (1–10B) vs. large (>10B parameters)

  4. Resource constraints: compute budget, hyperparameter tuning capacity, tolerance for training instability

Analysis Goal.

Exploratory discovery, where the question is what features exist rather than whether a particular one does, is the setting SAEs were designed for and the one the comparisons below address. For targeted investigation of an already-identified behaviour, where the concepts of interest are determined, supervised methods such as DAS (Geiger et al., 2024) and linear probes are more direct instruments. For online deployment and monitoring, SAEs with small dictionaries can be preferable for low inference cost.

Layer Type.

Layer types differ in their activation properties, so the right variant depends on what each can represent, not just how well. On the residual stream, single-layer SAEs apply directly, and the choice reduces to the resource considerations below. On MLP outputs, transcoders are the appropriate tool: a single-layer SAE cannot span the nonlinearity, so transcoders learn the input-to-output map directly (Dunefsky et al., 2024), and Paulo et al. (2025c) reported favourable comparisons against SAEs there. On attention outputs, standard and Gated SAEs both have been used; attention-specific variants remain underdeveloped, making this the least studied of the three sites. For cross-layer analysis, crosscoders (Lindsey et al., 2024) and cross-layer transcoders (Ameisen et al., 2025) track feature evolution across layers at substantially higher compute cost, and a crosscoder trained jointly on two models is the reported approach for comparing representations between them. Resource Constraints.

Under limited compute, or where fast iteration matters more than reconstruction quality, Top-k SAEs (Gao et al., 2025) are the practical choice: fixing \|z\|_0 \le k removes the sparsity coefficient \lambda from the search space entirely rather than requiring it to be tuned, with reported values commonly in the range k = 32 (Gao et al., 2025) to 150 (Karvonen et al., 2025). With moderate tuning capacity, Gated SAEs (Rajamanoharan et al., 2024a) achieved a better reconstruction–sparsity trade-off while retaining \lambda. They also avoid the shrinkage effect by separating feature detection from magnitude estimation. However, because the standard L_1 SAE is now used mainly as a baseline, comparisons against it partly reflect shrinkage rather than dictionary quality alone. When extensive tuning is plausible, JumpReLU SAEs (Rajamanoharan et al., 2024b) achieved the strongest reconstruction performance at matched sparsity by learning per-feature thresholds. However, gains on these sparsity–fidelity proxy metrics do not reliably translate into better downstream performance (Karvonen et al., 2025). In practice, selecting the best model and hyperparameters to achieve optimal performance can take a lot of time.

Model Scale.

The differences between variants depend strongly on the metric in models with roughly 1 or 2B parameters, such as Gemma-2-2B (Karvonen et al., 2025), which is the regime mainly used to validate methodology before scaling. For models between 1B and 10B parameters, JumpReLU SAEs and Top-k SAEs are the most commonly reported variants; Gemma Scope (Lieberum et al., 2024) uses the former and Llama Scope (He et al., 2024) the latter. For models larger than 10B parameters, Gemma Scope (Lieberum et al., 2024) (for Gemma 2 models) and Gemma Scope 2 (McDougall et al., 2025) (for Gemma 3 models) are the main open resources, both of which used JumpReLU SAEs. Additionally, Gao et al. (2025) explored scaling Top-k SAEs to GPT-4 (OpenAI et al., 2024), although GPT-4 itself is not publicly available.

6.5 Challenges and Failure Modes of SAEs#

SAEs have become a standard tool for feature extraction, but they exhibit systematic failure modes that undermine their interpretability claims. It is therefore essential to understand these issues when using SAEs as mechanistic tools. This section provides a systematic discussion of them.

6.5.1 Dead Features#

A dead feature is an element in the learned dictionary that never activates or activates extremely rarely across training. Dead features waste the dictionary’s capacity, and they are common. In fact, they can constitute up to 10–50% of the dictionary in a poorly tuned SAE (Bricken et al., 2023).

Several factors can cause dead features to emerge. First, inappropriate SAE weight initialisation can place features in low-density regions of the activation space with weak gradient signals. Second, an overly strong sparsity penalty \lambda may suppress feature activations early in training, preventing features from contributing usefully to reconstruction. Finally, once a subset of features captures common, dominant patterns, the remaining features struggle to find useful roles for improving reconstruction and thus do not activate.

Dead features can be detected by tracking each feature’s rate of being activated during training. For example, features with an activation rate below 0.01% may be considered dead (the threshold should adapt across scenarios). Several mitigation strategies have been proposed, such as neuron resampling, which periodically reinitialises dead features using examples with high reconstruction error (Bricken et al., 2023). The sparsity penalty can also be reduced early in training and increased gradually (i.e., a warm-up schedule). More recent Batch Top-k SAEs allocate sparsity adaptively across samples, which allows more active features on complex inputs and fewer on easy ones (Bussmann et al., 2024).

6.5.2 Feature Duplication#

Feature duplication occurs when multiple features in the dictionary encode the same or similar concepts (Templeton et al., 2024), leading to potentially redundant features. Duplication can arise for several reasons: insufficient sparsity pressure, imbalanced training data, or an optimisation process that favours local minima with duplicated features. Duplication can be detected by computing pairwise cosine similarity between feature directions (i.e., decoder columns), where high similarity indicates potential redundancy. As duplicated features tend to activate together (Korznikov et al., 2025), co-activation statistics may provide complementary evidence.

6.5.3 Feature Absorption and Splitting#

Another class of failure modes concerns feature granularity. Feature absorption arises when semantically hierarchical features interact under the sparsity objective: a seemingly general (parent) feature fails to activate on some inputs where it should because a more specific (child) feature activates instead and has absorbed part of the parent’s direction into its own decoder direction (Chanin et al., 2025). For example, a “starts with S” feature may fail to activate on the token “short”, while a token-specific “short” feature with a partially overlapping direction activates instead. Absorption-induced false negatives make such a feature an unreliable detector of its concept. It can be detected by comparing the feature with a linear probe for the same concept: inputs on which the probe responds strongly, but the feature does not, while another active feature’s direction aligns with the probe, indicate absorption (Chanin et al., 2025).

By contrast, feature splitting occurs when a feature learned by a smaller SAE splits into multiple distinct features as the SAE scales up (e.g., by increasing the expansion factor e). This often produces more fine-grained features, which may be either beneficial or less useful. In a favourable case, an initially polysemantic or opaque feature, such as one activating on “bank” in both financial and geographical contexts, may split into more coherent features of “investment bank” and “river bank”. In a less useful case, the resulting features may become low-level, lexical detectors that activate on the token “bank” in any context.

6.5.4 Feature Instability Across Seeds#

SAE features are also sensitive to random initialisation, optimiser stochasticity, and data ordering. For a fixed SAE architecture and training dataset, different random seeds can produce substantially different dictionaries (Paulo & Belrose, 2026). In practice, frequent and semantically clear features tend to be stable, while rare or context-specific features vary substantially. Often, fewer than 50% of features remain the same across seeds, although broader semantic clusters may remain more consistent. This instability limits the reliability of mechanistic claims based on individual SAE features. Although aggregating results across seeds can improve robustness, it increases computational cost. As a result, when evaluating SAEs, we should report feature stability across seeds alongside reconstruction loss.

6.5.5 Identifiability and Theoretical Concerns#

Another concern for SAE-based interpretability claims is whether the learned features are identifiable, that is, whether the dictionary learning reliably recovers the “true” underlying features—if such features exist—or merely finds one of many mediocre decompositions (Klindt et al., 2025).

Suppose activations are generated by some sparse latent process

h = D^{*} z^{*} + \epsilon ,

where D^{*} is the ground-truth feature dictionary and z^{*} are the feature coefficients. An SAE is identifiable if its training recovers D^{*} and z^{*} up to unavoidable symmetries such as feature permutation and rescaling.

In classical dictionary learning, identifiability holds under low-coherence conditions, i.e., dictionary elements are sufficiently orthogonal to one another. However, when coherence is high, ambiguity arises: multiple distinct sparse combinations of features from the same dictionary can generate the same output (Schnass & Vandergheynst, 2008). In large language model activations, high coherence is likely unavoidable because of the model’s complicated internal structure and correlations within its feature space (Li et al., 2025b). So far, identifiability remains a stubborn issue in SAEs, even though it offers a theoretical explanation for several empirical observations.

Recent progress in fine-tuning language models around a fixed sparse autoencoder offers a potential path forward. In this setting, model activations are explicitly constrained to be sparse combinations of decoder features while largely preserving task performance (Chen et al., 2025a). In particular, recent work aimed at limiting superposition fine-tunes the language model jointly with the SAE while enforcing orthogonality constraints on the decoder matrix (Miller et al., 2026). By explicitly imposing low-coherence conditions, this approach improves identifiability: activations have a unique feature representation, and these features can be reliably recovered.

Relation to Causal Relevance.

The concern of identifiability connects to causal relevance: even if an SAE feature is monosemantic and helps reconstruct activations well, it may not correspond to a causally meaningful unit of analysis. Below, we summarise some criteria for validating an SAE feature.

Diagnostic criteria:

  • Necessity: Does ablating the feature remove the corresponding concept in model responses? Low necessity suggests that the concept can be expressed through redundant features.

  • Sufficiency: Does activating only this feature produce the behaviour corresponding to its concept? Low sufficiency suggests the feature alone is not enough to represent the concept.

  • Specificity: Does the feature’s causal effect match its corresponding concept? Low specificity means the feature contains other concepts.

These criteria are useful in practice when claiming that SAE features represent meaningful units of analysis.

6.5.6 Practical Recommendations#

The challenges discussed above suggest several methodological considerations for SAE-based interpretability studies:

  1. Report failure-mode metrics: Alongside reconstruction loss, researchers should also report dead-feature percentage, duplication rate, and stability across seeds.

  2. Validate causal relevance: Researchers should validate features’ necessity, sufficiency, and specificity through interventions (e.g., feature ablation or steering) and evaluation on downstream effects.

  3. Compare methods: For safety-critical applications, researchers should compare SAE features against various baselines to assess whether SAEs recover the relevant structure.

  4. Try multiple SAE variants: Different variants (e.g., Gated, Top-k, JumpReLU) impose different inductive biases. Researchers can explore findings consistent across variants, as these provide stronger evidence.

  5. Acknowledge identifiability limits: Researchers should frame SAE features as one valid approximate decomposition rather than the true features. Multiple decompositions may be equally valid for reconstruction but yield different feature sets.

  6. Consider alternatives for targeted analysis: When specific concepts are the focus, supervised methods (e.g., DAS, probes, discussed in Section 6.9.4) may be more reliable because SAEs discover features in an unsupervised and exploratory manner.

6.6 Multi-Layer Feature Extraction and Analysis#

Standard SAEs analyse individual layers in isolation. However, features can evolve as information propagates through the network. Transcoders (Figure 7a), cross-layer transcoders (Figure 7b), and crosscoders (Figure 9) enable multi-layer feature extraction and analysis, revealing how representations and features associated with particular model components—most commonly MLP blocks—transform across depth.

6.6.1 Transcoders: Bridging the Nonlinearities#

A transcoder learns a sparse mapping between the input to and output of a model component, such as an MLP block, in layer \ell: h_{\ell}^{\text{out}} \approx W_{\text{out}} z + b_{\text{out}}, \quad z = \sigma(W_{\text{in}} h_\ell^{\text{in}} + b_{\text{in}}) where z \in \mathbb{R}^{d_{\text{sparse}}} are sparse feature activations bridging the nonlinearity between input and output of the MLP, and W_{\text{out}} \in \mathbb{R}^{d \times {d_{\text{sparse}}}} and b_{\text{out}} \in \mathbb{R}^{d} are decoder D parameters. The transcoder reconstructs post-nonlinearity activations using features extracted from pre-nonlinearity activations (Dunefsky et al., 2024).

Architecture and Motivation.

Standard SAEs do not explain the nonlinear transformations (i.e., weight matrices of MLP blocks and attention heads) themselves that produce the activations. A transcoder achieves this by applying dictionary learning to the mapping, learning features that explain the transformation. Its training minimises \mathcal{L} = \|h_{\ell}^{\text{out}} - (W_{\text{out}} z + b_{\text{out}})\|_2^2 + \lambda \|z\|_1, where z = \sigma(W_{\text{in}} h^{\text{in}}_\ell + b_{\text{in}}) as defined above.

When Are Transcoders Necessary?

SAEs extract features from static activations and thus often suffice for residual-stream analysis. Transcoders track how features emerge from input to output and are essential for analysing MLP layers (Dunefsky et al., 2024).

6.6.2 Cross-Layer Transcoders: Enabling Better Circuit Analysis#

Cross-layer transcoders (CLTs) are sparse feature decompositions spanning all layers of a neural network. At each layer \ell, sparse feature activations are read from the residual stream via z_{\ell} = \sigma_{\text{JumpReLU}} \!\left( W_{\text{in}}^\ell h_{\ell}^{\text{in}} \right), where z_\ell^j denotes the activation of feature j at layer \ell.
Each feature can write to the MLP outputs of its own layer and all subsequent layers through layer-specific decoder vectors. The contribution from features read at layer \ell to the MLP output at a subsequent layer \ell' is \hat{h}_{\ell \to \ell'}^{\text{out}} = \sum_j W_{\text{out},j}^{\ell \to \ell'} z_{\ell}^{j}, where W_{\text{out},j}^{\ell \to \ell'} is the decoder vector from feature j at layer \ell to the MLP output at layer \ell'. The reconstructed MLP output at layer \ell' is then \hat{h}_{\ell'}^{\text{out}} = \sum_{\ell=1}^{\ell'} \hat{h}_{\ell \to \ell'}^{\text{out}} = \sum_{\ell=1}^{\ell'} \sum_j W_{\text{out},j}^{\ell \to \ell'} z_{\ell}^{j}, which approximates the original MLP output h_{\ell'}^{\text{out}}.

CLTs (Figure 7b) are trained jointly across all L layers to minimise \mathcal{L} = \sum_{\ell'=1}^{L} \left\| \hat{h}_{\ell'}^{\text{out}} - h_{\ell'}^{\text{out}} \right\|_2^2 + \lambda \sum_{\ell=1}^{L} \sum_j \tanh\!\left( c\, z_{\ell}^{j} \sqrt{ \sum_{\ell'=\ell}^{L} \left\| W_{\text{out},j}^{\ell \to \ell'} \right\|_2^2 } \right), where c is the sharpness hyperparameter (Ameisen et al., 2025).

Replacement Models and Attribution Graphs.

A key insight is that CLTs enable the construction of a replacement model—a version of the original model in which all MLP layers are replaced with their CLT reconstructions. Running this replacement model involves:

  • Computing CLT feature activations z_{\ell} at each layer \ell

  • Replacing MLP outputs h^{\text{out}}_{\ell} with reconstructions \hat{h}^{\text{out}}_{\ell} from features in layer 1 through \ell

  • Keeping attention layers unchanged

When analysing a specific prompt, the replacement model freezes the original model’s attention patterns and normalisation statistics from its forward pass, then adds layer-specific error corrections. Under these conditions, the local replacement model can exactly match the original model’s activations on that prompt while decomposing it into interpretable CLT features. However, when the model’s activations are completely replaced by CLT reconstructions, the intervened model’s top-1 predictions match the original model’s on only about 50% of prompts from the Pile dataset (Gao et al., 2020). Notably, this experiment uses a relatively small, 18-layer transformer (Ameisen et al., 2025). Therefore, this figure should be interpreted with important caveats (see below).

CLTs have been claimed to possess high output fidelity given that they achieve high top-1 token agreement. However, this claim requires careful examination:

Conditions for reported fidelity:

  • Results are reported primarily on toy or small models, whose generality to other model architectures (e.g., Llama, Qwen) and model sizes (e.g., 70B models) is underexplored.

  • Fidelity was measured on short sequences in the CLT training data. Evaluation under distribution shift (e.g., out-of-domain tasks, adversarial inputs) is not adequate.

  • The paper reports top-1 token agreement as the main result, while softer metrics (e.g., top-5 agreement, KL divergence) may show different patterns and insights.

Conditions for exact local matching:

  • Attention patterns must be frozen from the original forward pass since the CLT does not compute or reconstruct attention computations.

  • Layer normalisation statistics (means, variances) must be cached from the original model. The replacement model does not recompute these.

  • Error correction terms are added per layer to compensate for reconstruction residuals. Without them, exact matching fails.

Factors affecting fidelity:

  • Model scale: Preliminary evidence suggests that reconstruction quality and feature interpretability improve with CLT model size. This may be because larger CLTs produce more structured, less entangled representations (Ameisen et al., 2025). However, systematic scaling studies are limited.

  • Layer depth: Early layers’ and late layers’ activations are usually input-specific and output-constrained, respectively. Middle layers have richer information derived from the input but are not yet converged to the output. As a result, middle layers often show higher reconstruction fidelity.

  • Domain: Fidelity on factual recall and syntactic tasks is higher than on complex reasoning or arithmetic tasks, where MLP computations may be more complex and cannot be approximated by sparse linear features.

These caveats do not invalidate CLTs as a tool for mechanistic analysis, but they do mean that fidelity should be verified on the target model and specific task before drawing strong conclusions from CLT-based circuit analysis.

Why CLTs Enable Better Circuit Analysis.

Unlike per-layer transcoders, CLTs reveal direct feature-to-feature interactions across layers: a feature in layer \ell directly influences features in later layers through its contribution to their inputs. This simplifies circuit structure—features need not re-encode information at each layer. Additionally, replacing MLPs with CLT reconstructions makes the remaining computation approximately linear (with frozen attention patterns and normalisation), enabling principled attribution: each feature’s activation can be expressed as the sum of its input edges up to its activation threshold (Ameisen et al., 2025).

However, linearisation depends on several assumptions:

  • Attention freezing: By caching attention patterns, the replacement model treats attention as a fixed routing operation rather than a dynamic, input-dependent computation. This means CLT-based circuits describe model computation conditioned on given attention patterns without analysing them.

  • Normalisation caching: CLT analysis caches the input-dependent normalisation factors (e.g., LayerNorm denominators) from the original forward pass and reuses them during attribution instead of recomputing them after interventions. This removes a source of nonlinearity, but if an intervention would substantially change these normalisation factors in the original model, the cached computation no longer faithfully represents the intervened state.

  • Sparse linear approximation: Dictionary learning methods assume MLP outputs or transformations are well approximated by sparse linear combinations of features. This assumption may fail when computations involve complex feature interactions or highly nonlinear transformations.

CLTs provide a powerful lens for circuit discovery when these assumptions hold. When they fail, CLT-based explanations may become unfaithful.

Computational Cost and Practical Considerations.

Let d_{\text{sparse}} = ed, where e is the expansion factor. For a transformer with L layers, a complete suite of CLTs contains L encoders mapping \mathbb{R}^d \rightarrow \mathbb{R}^{ed} and L(L+1)/2 decoders mapping \mathbb{R}^{ed} \rightarrow \mathbb{R}^d. The resulting parameter count, with biases ignored, is therefore N_{\text{CLT}}(L,d,e) = \frac{e d^2}{2}\left(L^2 + 3L\right), which highlights the quadratic scaling with both model depth and hidden dimension, as illustrated in Figure 8.

Training a suite of CLTs thus incurs a high upfront cost. For reference, training the CLT suite for Gemma-2-9B required approximately 3,844 H100 GPU-hours at 50% FLOPs efficiency (Ameisen et al., 2025). This cost is amortised over many circuit analyses on the trained CLT. The resulting interpretability gains (cross-layer features, lower interference, better attribution) justify the investment for systematic mechanistic analysis.

For these reasons, current applications of CLTs remain limited: a “greater-than” mechanism study (Merullo et al., 2025), an open-source extension (Lindsey et al., 2025a), and analysis of multilingual representations using CLTs (Harrasse et al., 2026). This scarcity of downstream use cases likely reflects the considerable challenges of training CLTs at scale and the complexity of using CLT-based circuit discovery in the wild.

Open Questions for CLT Research.

Several important questions remain open:

  • How does CLT fidelity scale in large models? How can we better measure fidelity?

  • Can CLTs be extended to model more nonlinearities such as attention patterns and normalisation, while maintaining their explanatory power?

  • Can we develop evaluation protocols that reliably detect the potential unfaithfulness of CLT-based explanations?

  • How sensitive are CLT circuits to experimental setups, such as the choice of training data?

6.6.3 Crosscoders: Analysing Cross-Layer Features#

A crosscoder learns a shared sparse representation from activations across L layers. It jointly encodes activations from all layers as z = \sigma_{\text{ReLU}} \left( \sum_{\ell=1}^{L} W_{\text{in}}^\ell h_\ell + b_{\text{in}} \right), where z \in \mathbb{R}^{d_{\text{sparse}}} denotes the shared sparse feature activations and W_{\text{in}}^\ell is the layer-\ell encoder. Each layer is then reconstructed using a layer-specific decoder: \hat{h}_\ell = W_{\text{out}}^\ell z + b_{\text{out}}^\ell, \qquad \ell = 1,\ldots,L. Thus, a single latent feature can capture patterns that are shared across, persist through, or vary across multiple layers of the residual stream (Lindsey et al., 2024). Studies have also used crosscoders to discover shared features in activations from different models (Ge et al., 2026; Bayazit et al., 2026; Lindsey et al., 2024; Jiralerspong & Bricken, 2025), as detailed in Section 9.1.

A crosscoder is trained by minimising \mathcal{L} = \sum_{\ell=1}^{L} \left\| \hat{h}_\ell - h_\ell \right\|_2^2 + \lambda \sum_j \left( \sum_{\ell=1}^{L} \left\| W_{\text{out},j}^{\ell} \right\|_2 \right) z^j, where W_{\text{out},j}^{\ell} denotes the decoder vector of feature j at layer \ell, and \lambda controls the sparsity penalty.

Causal vs. Acausal Crosscoders.

Crosscoders support two information flow patterns:

  • Causal Crosscoders: Read only from layers \ell' \leq \ell at the current position. This respects the forward pass causality: earlier layers cannot read from later layers.

  • Acausal Crosscoders: Read from any layer \ell' regardless of depth ordering. Useful for understanding post-hoc feature relationships across the full model.

Applications to Circuit Analysis.

By extracting cross-layer features, crosscoders help us understand how features propagate through the residual stream across layers, removing duplicate feature representations that complicate circuit analysis. This simplification allows features to “jump” across intervening identity operations, substantially reducing circuit complexity. More importantly, crosscoders reveal how input-relevant features transform as they flow through the network, distinguishing which features persist unchanged versus which are actively modified by downstream computation (Lindsey et al., 2024).

6.7 Comparing SAEs, Transcoders, and Crosscoders#

Single-layer SAEs are efficient and locally interpretable but miss cross-layer feature evolution. Transcoders improve this by imitating MLP behaviour and revealing nonlinear transformations, though they require sequential analysis across depth. Cross-layer transcoders span multiple layers for global information flow but are extremely expensive. Crosscoders take a different approach, extracting shared features across layers simultaneously to resolve cross-layer superposition and simplify circuits without chaining predictions.

6.8 Case Study: Induction Heads#

Here, we examine induction heads (Olsson et al., 2022), a mechanism found in many modern language models, as a case study. We first describe their conditional-copying function and role in in-context learning, and then relate them to feature-extraction methods such as SAEs and CLTs, which reveal how this computation can be distributed across broader feature circuits.

Induction heads, first identified and analysed by Elhage et al. (2021), are attention heads that implement a conditional copying rule over repeated subsequences. Let x=(x_1,\dots,x_T) be a token sequence, and consider positions i<j<T such that x_i=x_j. An attention head indexed r (see Section 4.4 for an introduction to attention modules) is said to be an induction head when its attention pattern assigns comparatively high attention weight from position j to position i+1 (i.e., high A^r_{j,i+1}) and its residual-stream update \Delta h^r = W_O^r V^r (A^r)^\top increases the model’s logit for token x_{i+1} when predicting the token at position j+1.
That is, induction heads implement the rule (x_i=x_j) \;\Rightarrow\; \hat{x}_{j+1}\approx x_{i+1}. They help enable in-context prediction by copying the continuation that followed an earlier occurrence of the same token.

Consider the sequence \texttt{A B C A B} where the model needs to predict the token after the second B. Observing the repeated prefix A B, an induction head attends from the second B to the position after the first B and contributes to the model’s prediction of C. This induction behaviour should generalise across tokens and positions.

Induction heads were originally characterised as specific attention heads implementing this copying rule. However, subsequent work shows that we can understand the underlying computation more naturally at the level of distributed representations than isolated model components.

Feature extraction methods, such as SAEs, can decompose attention layer outputs into sparse, interpretable features that capture meaningful activation patterns beyond individual attention weights (Kissane et al., 2024). Modern analyses suggest that induction heads are not isolated mechanisms but participate in distributed feature circuits, where multiple interacting features recur and compose across layers (Dunefsky et al., 2024; Singh et al., 2024; Kissane et al., 2024; Kamath et al., 2025).
SAEs trained on attention heads’ activations reveal feature families of recurring patterns and contextual dependencies. Some of them align with behaviours originally attributed to induction heads (Kissane et al., 2024). By analysing these features, we can understand how models maintain and manipulate information across tokens and contexts.
Cross-layer analyses, including crosscoders, suggest that certain features are represented consistently across layers rather than being recomputed at each layer (Lindsey et al., 2024). This perspective highlights that attention heads, including specialised ones such as induction heads, may be only part of broader, distributed feature representations.

6.9 Comparison with Alternative Feature Extraction Methods#

Besides SAEs, alternative techniques from signal processing and machine learning have also been adapted to extract features from neural networks. They make different modelling assumptions and therefore offer distinct trade-offs in interpretability, scalability, and robustness. Table 6 summarises the methods discussed in this section.

6.9.1 Non-Negative Matrix Factorisation (NMF)#

Non-negative matrix factorisation (NMF; Lee & Seung, 1999) decomposes a non-negative activation matrix H \in \mathbb{R}^{d \times n} as H \approx WA, where both the feature dictionary W \in \mathbb{R}^{d \times m} (m is the preset number of features) and the coefficient matrix A \in \mathbb{R}^{m \times n} are constrained to have non-negative elements. Because all components are non-negative, each feature contributes positively to the final representation, making it easier to interpret. Additionally, classical NMF’s optimisation process uses simple multiplicative update rules that preserve non-negativity. Moreover, under assumptions like separability (each latent feature appears in at least one sufficiently “pure” example), NMF guarantees that the recovered decomposition is unique (Donoho & Stodden, 2003).

However, classical NMF is not suitable for neural network activations because they can have negative elements, requiring additional preprocessing steps that may distort the activation-space structure. Moreover, NMF does not explicitly encourage feature sparsity, and scaling NMF to large dictionaries is computationally expensive. As a result, empirical work on extracting and analysing features in neural network activations has largely focused on Semi-NMF (Ding et al., 2010), which relaxes the non-negativity constraint on W. Shafran et al. (2026) showed that Semi-NMF can recover features competitive with SAEs on small-scale evaluations, but systematic comparisons at large scale remain limited. Yun et al. (2021) used a Semi-NMF-like approach to factorise BERT’s contextualised hidden-state representations (Devlin et al., 2019), allowing elements in W to take both positive and negative values while constraining A to be non-negative.

6.9.2 Principal Component Analysis (PCA)#

Principal Component Analysis (PCA; Pearson, 1901; Hotelling, 1933) decomposes activations by finding an orthonormal basis of directions that maximise explained variance. Given a mean-centred activation matrix H \in \mathbb{R}^{d \times n}, where each column is an activation vector, PCA computes a low-rank approximation H \approx U \Sigma V^\top, where the columns of U are the principal directions ordered by explained variance. PCA is fast, stable, and scalable. However, PCA imposes constraints and inductive biases that may misalign with neural network activations. Specifically, it identifies principal directions that maximise explained variance in the activation distribution, but much of the information of interest is region- or context-dependent and cannot be captured by variance alone. Moreover, PCA constrains the principal directions to be orthogonal, but in practice the underlying features correlate or partially overlap. Recent benchmarks (Wu et al., 2025b) reflect this misalignment: PCA underperformed most baselines, including SAEs, on both steering and concept-detection evaluations. While PCA can outperform SAEs in some localisation settings (Mueller et al., 2025), it still generally lags behind simple supervised baselines.

6.9.3 Independent Component Analysis (ICA)#

Independent Component Analysis (ICA; Hyvärinen & Oja, 2000) decomposes activations H \in \mathbb{R}^{d \times n} as H \approx WS, where n is the number of data points. Note that ICA may look similar to NMF at first glance. However, they were developed for different use cases and thus rely on different assumptions and optimisation procedures. In ICA, each column in W \in \mathbb{R}^{d \times m} is a mixing vector, and m is the number of different source signals; each row in S \in \mathbb{R}^{m \times n} is a source signal (a signal has n data points), with m source signals in total. These signals are optimised to be independent of one another. Thus, if model activations are linear mixtures of statistically independent “foundational features”, ICA can provably recover those features.

However, these assumptions may not hold for neural network activations. Specifically, classical ICA typically expects the completeness property (number of latent sources equals the dimensionality of the observed representation), and overcomplete decompositions (which are what we expect in activations) would require additional extensions (Lewicki & Sejnowski, 2000). Moreover, underlying features may not be statistically independent, which further limits the applicability of classical ICA. Although early studies applied it to analyse neural network activations, they did not find interpretability gains over SAEs (Cunningham et al., 2024). This may partly reflect the challenges discussed above.

More recently, however, Liu & Han (2026) showed that ICA can achieve performance comparable to that of SAEs, arguing that its previously reported underperformance may stem from limitations of classical ICA implementations poorly suited to the scale and statistical structure of neural network activations. These findings leave open whether ICA should be regarded primarily as a simple classical baseline or as an approach with underestimated, substantial headroom for further development.

6.9.4 Supervised Feature Extraction Methods#

When the concepts of interest are known in advance, supervised methods can directly optimise representations aligned with those targets. Examples include distributed alignment search (DAS), which uses supervision to learn a change of basis that aligns representations with high-level causal variables (Geiger et al., 2024); Supervised Multi-Dimensional Scaling (SMDS), which projects activations to preserve concept-level similarities (Tiblias et al., 2026); and probes, which fit a concept direction in contrastive class-conditioned activations (Marks & Tegmark, 2024).

Notably, despite its simplicity, probing has outperformed SAEs in concept detection (Wu et al., 2025b). It has also become a standard tool for identifying safety-relevant concepts in model representations, including refusal behaviour and implanted backdoors (Arditi et al., 2024; MacDiarmid et al., 2024). We discuss probing in detail in Section 8.6. We put it under Section 8 because we view its central methodological contributions and technical challenges as the readout of human-interpretable information—often expressed in natural language—from model activations, rather than the extraction of monosemantic features or causal variables.

When labelled data is available, supervised approaches often outperform SAEs on concept detection and steering tasks (Huang et al., 2024; Wu et al., 2025b; Chaudhary & Geiger, 2024). They also avoid choosing dictionary sizes or sparsity penalties, since the concept set determines complexity. However, these methods require labelled data for each concept and cannot discover previously unknown features. Therefore, supervised methods suit settings where predefined, crisp concepts matter, whereas SAEs remain preferable for exploratory analysis.

6.9.5 Dictionary Learning Baselines#

Classical dictionary learning methods provide useful baselines for evaluating SAEs. Techniques such as K-SVD alternate between sparse coding and dictionary updates and converge under certain conditions (Aharon et al., 2006). Comparative studies suggest that SAEs’ primary advantage is fast inference because the encoder learns to decompose all activations, while potentially sacrificing optimal sparsity (O’Neill et al., 2025). As such, classical dictionary learning can still achieve superior dictionary quality in some cases and thus remains an important reference point for assessing the added value of SAEs.

6.10 Interpretability-by-Design Methods for Intrinsic Interpretability#

The methods surveyed thus far in this section aim to extract and analyse more monosemantic units from polysemantic model activations. They share a common premise: the model’s original representations are too entangled to be directly interpretable, so interpretability is applied post hoc to recover simpler units of analysis. A parallel research programme, which we term Interpretability-by-Design Methods for Intrinsic Interpretability, inverts this premise by asking whether deep neural models can instead be designed to be mechanistically interpretable by construction (Pearce et al., 2025; Park et al., 2025; Oldfield et al., 2024; Yang et al., 2025; Gao et al., 2026; Adler et al., 2025; Draye et al., 2026; Dooms et al., 2025). This subsection extends the discussion of this research direction.

Next, we introduce five approaches for constructing models that are more interpretable by design. Three impose model sparsity constraints at different levels: feature-sparse training (Section 6.10.1), weight-sparse training (Section 6.10.2), and attention-sparse training (Section 6.10.3). The remaining two approaches instead modify the computational primitives themselves, using more interpretable operators as units of construction and analysis (Sections 6.10.4 and 6.10.5).

Interpretability should be understood as a spectrum rather than a binary property. At least in their current form, these techniques do not make model computation completely or immediately understandable. Instead, they make models easier to analyse and ensure the analysis pipeline preserves more information about the original computation than post-hoc approximations. Table 7 summarises these approaches and their trade-offs.

6.10.1 Feature-Sparse Training: SoLU#

Softmax linear units (SoLU; Elhage et al., 2022b) are an earlier attempt at architectural intervention. SoLU is a specialised activation function that applies a softmax-based transformation across the layer’s d_{\mathrm{mlp}} neurons. Specifically, given the pre-activation vector u = W_1 h + b_1 \in \mathbb{R}^{d_{\mathrm{mlp}}}, SoLU calculates the activation values as \begin{equation*} \sigma_{\text{SoLU}}(u) = u \odot \mathrm{softmax}(u). \tag{3} \end{equation*} This softmax-based transformation induces competition among neurons. When one neuron receives a large pre-activation value, the softmax suppresses the others’ values, analogous to lateral inhibition. This competition encourages certain neurons to specialise and dominate, increasing the prevalence of monosemantic neurons associated with human-interpretable concepts.

However, it also reveals an undesirable phenomenon: although many secondary neurons’ activations are suppressed to low magnitudes, these neurons remain polysemantic, with many features compressed into them. Later layer normalisation (Ba et al., 2016) can amplify them and recover the polysemanticity property (Elhage et al., 2022b). The “smuggling” by layer normalisation suggests that imposing local interpretability constraints may not eliminate neural networks’ incentive to compress information through superposition. This issue motivates global constraints across the neural network, such as weight-sparsity training discussed below.

6.10.2 Weight-Sparse Training#

A weight-sparse transformer (Gao et al., 2026) treats weight sparsity as an explicit structural constraint that is progressively strengthened during training. Gao et al. (2026) optimise the standard cross-entropy objective along with an L_0 constraint on model weights after each optimisation step. Specifically, within each weight matrix, they retain only the largest-magnitude parameters and set the rest to zero. The L_0 constraint anneals from a dense initialisation to the desired sparsity level over training. The resulting transformer has most weight parameters exactly zero, making the remaining computational structure much easier to decompose into small, task-specific circuits.

Its interpretability gains can be substantial. Under highly sparse regimes (e.g., <1\% active weights), neurons receive input from far fewer upstream neurons, and the model’s circuits for specific capabilities or behaviours become much sparser. Mean-ablation experiments further confirm that these circuits are both necessary and sufficient for the capability or behaviour.

Gao et al. (2026) characterised the trade-off between model capability and interpretability induced by weight sparsity. Increasing sparsity generally makes the model easier to decompose into small, interpretable circuits. However, it also degrades task performance, producing a capability–interpretability Pareto frontier. Nonetheless, the authors found that increasing model size can shift this frontier outward. At comparable task performance, larger sparse models can have substantially smaller, more interpretable circuits than smaller models; at comparable interpretability, they can retain stronger capabilities. This suggests that scaling model size alongside structural sparsity may offer a path to more interpretable yet high-capability models. However, preserving interpretability beyond tens of millions of nonzero parameters remains challenging, and weight-sparse training currently requires substantially more compute than traditional training.

Table 7: Comparison of interpretability-by-design methods.
Method Approach Interpretability Gain Primary Limitation
Feature-Sparse Training (SoLU) Softmax-gated activation function Increased neuron monosemanticity Layer normalisation smuggling displaces superposition
Weight-Sparse Training L_0 constraint on parameters More monosemantic neurons and much smaller circuits Training instability and scalability
Attention-Sparse Training L_0 regularisation on attention Makes attention patterns interpretable Requires fine-tuning on a trained language model
MOLT Sparse mixture of linear transforms Reveals implemented operations directly Complexity of matrix analysis

6.10.3 Attention-Sparse Training#

In transformers, attention patterns produced by an attention head are usually diffuse, i.e., every token attends to every other token. Diffuse attention patterns are difficult to interpret and audit. Previous studies have therefore explored attention-sparse training, which aims to sparsify attention patterns to make them more interpretable (Lei et al., 2025; Draye et al., 2026). Specifically, Lei et al. (2025) proposed SPARse TrANsformer World model (SPARTAN), an object-centric world model trained with L_0 regularisation on attention patterns and a constrained optimisation objective to maintain cross-entropy performance equal to that of a dense counterpart. Draye et al. (2026) further adapted this technique to fine-tune and sparsify a trained language model’s attention patterns.

After training (either from scratch or via fine-tuning), each attention head attends only to specific tokens, and the model performance remains close to the original. This result suggests that many attention patterns may be redundant noise. In CLT-based circuit discovery (see Section 7.2), Draye et al. (2026) showed that sparsified attention patterns reduce the number of mediating components involved in feature-to-feature attribution, making the resulting attribution graphs easier to analyse.

6.10.4 Modifications of Computational Primitives: MOLT#

One alternative approach to learning interpretable structure is to reconsider what the computational primitives should be (Oldfield et al., 2025; Park et al., 2025; Braun et al., 2025; Bushnaq et al., 2025). A recent example is the sparse mixture of linear transforms (MOLT), which represents a conceptual shift from feature extraction towards transformation extraction (Lindsey et al., 2025b).

Standard SAEs and transcoders primarily decompose model activations into features. However, many algorithmic tasks, such as arithmetic or geometric reasoning, are more naturally described by operations such as “add 3” or “rotate a vector”. In these tasks, we want to know how the model transforms one activation into another through components like weight matrices in MLP blocks. To achieve this, MOLT replaces the MLP with a sparse mixture of learned linear transformation matrices. The basic unit of analysis becomes transformations applied to model activations rather than features.

For example, in a modular arithmetic task, MOLT can represent the concept of addition with a learned rotation matrix, which relates more directly to the underlying algorithm than a collection of state-specific features. More broadly, approaches that represent computational operations explicitly, as MOLT does, may facilitate the development of interpretable representations for tasks governed by systematic operations. We view Kolmogorov–Arnold Networks (KANs) as an approach that embodies this idea, as discussed below.

6.10.5 Kolmogorov–Arnold Networks (KANs)#

Kolmogorov–Arnold Networks (KANs) represent one of the most radical departures from standard neural network architectures (Liu et al., 2025b). In conventional neural networks, each neuron receives outputs from upstream neurons through incoming edges weighted by scalar parameters, sums these weighted inputs, and then applies a fixed nonlinear activation function (the whole process can be represented as matrix multiplication in components like MLP blocks and attention modules in Section 4.4). Inspired by the Kolmogorov–Arnold representation theorem, KANs place learnable nonlinear functions, typically parameterised using B-splines, on edges rather than using fixed nonlinear activation functions at nodes.

Specifically, consider a single KAN node receiving an input vector v = (v_1, \dots, v_d) \in \mathbb{R}^d from the previous layer. Its output is y = \sum_{i=1}^{d} \psi_i(v_i), \qquad \psi_i(v_i) = \sum_{m} c_{i,m} B_m(v_i), where B_m(\cdot) denotes the m-th basis function, such as a cubic B-spline basis, and c_{i,m} is a learnable scalar coefficient. In this formulation, the edge is not scalar multiplication but a learnable univariate function \psi_i(\cdot), and a node simply sums the outputs of its incoming edges. Intuitively, KANs shift nonlinear transformations from nodes to edges, offering an alternative way to structure and interpret neural network computations.

This design gives KANs an explicitly compositional and thus more interpretable structure. As the nonlinearities are univariate and can be visualised directly on individual edges, researchers can use techniques like symbolic regression to approximate and inspect the learned analytical expressions, such as rediscovering known physical equations. Although KAN training is currently more computationally expensive than training standard MLPs and has not yet been convincingly demonstrated at the scale of large language models, this architectural innovation points to an ambitious direction towards interpretable neural networks in which parameters correspond to mathematically meaningful functions.

Summary.

This section introduced several classical methods for feature extraction and analysis, followed by approaches that aim to make models intrinsically interpretable. However, whether features are recovered post hoc or induced by design, they remain units of analysis rather than complete explanations of the model’s mechanism, i.e., how these units interact and causally influence one another. Section 7 therefore shifts from individual features to circuits: computational graphs of interacting components that describe how the model implements its behaviours.
